Datos canónicos: `company_id`, `instrument_id`, bolsa, divisa, sector, métrica, valor/unidad, período y límites, publicación/actualización, fuente, tipo, disponibilidad, norma y revisión. El DEMO usa esta forma pero **no prueba** cobertura real, parsers XBRL, TTM, FX, revisiones ni sesgos point-in-time.

## Stack, documentos, IA y despliegue evaluados

- [FastAPI](https://fastapi.tiangolo.com/features/): Pydantic y OpenAPI; integración sencilla con Python. [Vite](https://vite.dev/guide/): build SPA para un espacio privado. [Next.js](https://nextjs.org/docs/app/getting-started/installation): alternativa válida si se necesita SSR; no seleccionado para este hito.
- [SQLite FTS5](https://www.sqlite.org/fts5.html): búsqueda local por palabras y BM25; [WAL](https://www.sqlite.org/wal.html): concurrencia local limitada. PostgreSQL cuando sea necesario acceso remoto/concurrencia mayor. No hay infraestructura aprovisionada.
- [pypdf](https://pypdf.readthedocs.io/en/stable/user/extract-text.html): extracción y layout; no sustituye OCR ni lectura visual de fórmulas. openpyxl para lectura de hojas/celdas y fórmulas sin ejecutarlas. Versiones resueltas en `uv.lock`.
- IA: evaluar embeddings multilingües y generación sobre resultados de herramientas después de disponer de un conjunto de evaluación. No se elige un modelo por popularidad. [Controles de datos OpenAI](https://developers.openai.com/api/docs/guides/your-data) y [precios](https://developers.openai.com/api/docs/pricing) son referencias de una alternativa; no se ha activado una API ni estimado un coste sin volumen de tokens. Retención, residencia y derecho de transmisión requieren revisión previa.
- Seguridad: [OWASP sesiones](https://cheatsheetseries.owasp.org/cheatsheets/Session_Management_Cheat_Sheet.html). Uso remoto requerirá HTTPS, autenticación revisada, copias verificadas y gestión de secretos.
- Despliegue: proceso Python + build estático en un host privado; PostgreSQL/almacenamiento privado si se aloja fuera del equipo. Un host solo de frontend no basta para este backend. Sin proveedor de despliegue seleccionado ni gasto mensual comprometido. Coste incremental externo actual: cero servicios contratados; usa recursos del equipo.
