# Diseño de producto

Interfaz de investigación en español con navegación lateral y nombres técnicos reconocibles. Oscuro verde profundo, superficies discretas, acento salvia, ámbar para ausencia/incertidumbre y rojo para errores; el color siempre acompañado de texto. Modo claro mediante variables CSS. Tipografía del sistema sin fuentes ni recursos externos. SVG para proyecciones calculadas, sin series de precio inventadas.

## Información y flujos

Dashboard → screener → ficha ejecutiva/datos → DCF → watchlist → cartera → fuentes. Biblioteca y consulta documental accesibles desde toda la navegación. Market Intelligence muestra un estado pendiente con enlaces a fuentes evaluadas. La búsqueda global inicial cubre empresas y contenido documental; watchlists, informes y análisis guardados aún no se indexan globalmente.

## Wireframes funcionales

- Dashboard: título/acción, cuatro indicadores del espacio, tabla de empresas DEMO, proceso de investigación, valoraciones guardadas y acceso a biblioteca. No se inventa una cartera inicial.
- Screener: filtros, búsqueda, ordenación, resultados y exportación. Vista vacía sin coincidencias.
- Ficha: identidad/origen, indicadores, pestañas ejecutivo/avanzado; hipótesis DCF a la izquierda y resultado/proyecciones/puente/sensibilidad a la derecha.
- Cartera: valor/coste/resultados/dividendos, posiciones, formulario y libro cronológico. El valor del snapshot se distingue de una valoración actual.
- Biblioteca: métricas del catálogo, filtros, tarjetas, original PDF o Excel. Consulta: entrada, advertencia de alcance, fragmentos con enlaces a páginas.

## Estados y accesibilidad

Carga, errores de API, proveedor ausente, datos N/A, falta de resultados y modelo no aplicable. Formularios etiquetados, botones con nombre accesible, foco visible, estado de navegación y mensajes de error/success. Tablas desplazables con cabeceras. Menú móvil y rejillas adaptables; móvil no muestra gráficos recortados para aparentar una densidad mayor. Respeto de reduced motion. Se han previsto la revisión visual y teclado; no se afirma certificación WCAG.
